# Склад №4, блок 4-1 — 3D-модель (Buraq Logistics, Хоргос)

**Открыть модель:** `Sklad4_realistic_film.html` — двойной щелчок, Chrome или Edge.

Эта папка — полный проект: готовый файл, все исходники, из которых он собирается, проверки, рендер ролика в Blender,
документы и материалы заказчика. Всё, что нужно знать программисту или Claude Code, — в `CLAUDE.md`.

## Как продолжить работу в Claude Code
1. Распаковать папку `Sklad4_3D` целиком (например, в «Документы»).
2. Открыть эту папку в Claude Code как рабочую — `CLAUDE.md` в корне он прочитает сам.
3. Первым сообщением написать, например:
   > Прочитай CLAUDE.md и docs/. Собери проект и прогони проверки. Потом улучши графику модели — начни с того,
   > что даст самый заметный эффект на обычном ноутбуке. Покажи снимки до/после с одних и тех же точек.

Модель открывается без интернета (three.js встроен в файл). Для сборки нужен Python 3, для проверок — Node.js 18+ и Chrome или Edge (`npm install` один раз).

## Что где
| | |
|---|---|
| `Sklad4_realistic_film.html` | готовая модель (результат сборки) |
| `CLAUDE.md` | контекст проекта для Claude Code: устройство, координаты, ловушки, проверки, планы по графике |
| `build.py` | сборка: `python3 build.py` |
| `base/` | исходная модель заказчика — основа, не редактируется |
| `parts/`, `film/` | модули: материалы, постобработка, техника, люди, стойки, фильм, живой процесс |
| `assets/`, `vendor/` | модель человека, мокап, загрузчики three.js — встраиваются в файл |
| `tools/` | автоматические проверки в Chrome (см. `tools/README.md`) |
| `blender/` | цепочка рендера ролика в Blender Cycles |
| `docs/` | документ проекта с замечаниями по расстановке, DWS, материалы заказчика, снимки текущей версии; `docs/снимки_10.10_графика_физика/` — до/после улучшения графики, физики и моделей |
