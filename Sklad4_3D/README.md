# Buraq Logistics · Склад №4, блок 4-1 (Хоргос)

3D-модель склада, система управления складом (WMS), варианты хранения A/B/C и визуализация в Blender Cycles — один проект.

| Что | Файл |
|---|---|
| **Стартовая страница** со ссылками на всё | `index.html` |
| **Управление складом (WMS)** — сводка, схема ячеек, грузы, рейсы, клиенты, аналитика; данные из Google Sheets | `Buraq_WMS.html` |
| **3D-модель** — фильм процесса, живой процесс, обход, редактор, учёт груза в 3D | `Sklad4_realistic_film.html` |
| **Варианты хранения A/B/C** с оборудованием и симуляцией | `Sklad4_variants_ABC.html` |
| Кадры и пролёт Blender Cycles | `docs/снимки_18.11_WMS_Blender_фуры/` |

Все три HTML открываются и без установки — двойным щелчком (Chrome или Edge), без интернета.

## Развернуть у себя (например, в папке «AI projects»)

Нужны: [Git](https://git-scm.com), [Node.js LTS](https://nodejs.org). Для пересборки — [Python 3](https://python.org) (галочка «Add to PATH»).

**Windows** (PowerShell, путь к папке — свой):
```powershell
cd "$HOME\Documents\AI projects"
git clone https://github.com/Ziyod4433/print_decl.git buraq-sklad4
cd buraq-sklad4\Sklad4_3D
.\setup.bat
```
**macOS / Linux:**
```bash
cd ~/"AI projects"
git clone https://github.com/Ziyod4433/print_decl.git buraq-sklad4
cd buraq-sklad4/Sklad4_3D && ./setup.sh
```
`setup` ставит зависимости (один раз) и запускает локальный сервер — откроется браузер со стартовой страницей
(http://localhost:8080). Дальше — просто `npm start` в этой папке.

Обновиться до последней версии: `git pull` в папке `buraq-sklad4`.

## Команды

| Команда | Что делает |
|---|---|
| `npm start` | локальный сервер на http://localhost:8080 (только этот компьютер), открывает стартовую страницу; другой порт — `npm start -- 8090` |
| `npm run build` | собрать все три HTML из исходников (`build:model`, `build:abc`, `build:wms` — по одному) |
| `npm test` | быстрые проверки в Chrome/Edge: погрузчик, правка в фильме, планы фильма, учёт груза, WMS, обход (~5 мин) |
| `npm run check:sim` | живой процесс два полных цикла без столкновений (~12 мин) |

Полный список проверок — `tools/README.md` и `CLAUDE.md` §9.

## Продолжить работу в Claude Code

Откройте папку `buraq-sklad4/Sklad4_3D` в Claude Code (приложение Claude → Code → выбрать папку, или `claude` в терминале в этой папке).
`CLAUDE.md` в корне Claude прочитает сам — там устройство проекта, координаты, ловушки и проверки.

Чтобы облачная сессия Claude могла работать прямо в этой папке на вашем компьютере: в приложении Claude Desktop —
Settings → Claude Code → Remote Control, добавить папку и оставить приложение запущенным.

**Главное правило: правится исходник, а не готовый HTML** — готовые файлы перезаписываются при сборке.

## Что где
| | |
|---|---|
| `build.py` | сборка (вызывается через `npm run build`) |
| `base/` | исходная модель заказчика — основа, не редактируется |
| `parts/`, `film/` | модули 3D-модели: материалы, свет, техника, люди, стойки, машины, фильм, живой процесс |
| `stock/` | учёт груза в 3D (чтение таблиц Google, расстановка по ячейкам) — общий разбор таблиц с WMS |
| `wms/` | исходники WMS: `index.html` (вёрстка), `app.js` (приложение) |
| `abc/` | варианты хранения A/B/C и симуляция |
| `assets/`, `vendor/` | модель человека, мокап, запечённый свет зала, three.js r128 — встраиваются в файл |
| `tools/` | сервер (`serve.js`), сборка (`build_all.js`), проверки в Chrome (`check.js`, `checks/`), экспорт в Blender |
| `blender/` | кадры, пролёт и запекание света в Blender Cycles (см. `blender/README.md`) |
| `docs/` | замечания по расстановке, материалы заказчика, шаблон таблицы учёта, снимки по датам |

**Данные.** Ссылка на таблицу Google вводится в WMS или в модели и хранится только в браузере. В файлы проекта и в репозиторий
ссылки и данные таблиц не записываются (в таблицах клиенты, телефоны и цены).
